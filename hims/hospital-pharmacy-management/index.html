Common questions

Pharmacy management, answered.

Does the pharmacy get prescriptions automatically?

Yes. Doctor e-prescriptions flow straight to the pharmacy counter, so there is no re-typing and nothing is misread.

Does it track batch and expiry?

Yes. Every drug is tracked by batch and expiry, with alerts before items expire, so you sell first-expiry-first and cut wastage.

Does it do GST billing?

Yes. Pharmacy bills are GST-compliant and post to the same hospital billing, so counter sales and IP charges add up in one place.

Can it manage multiple counters or stores?

Yes. Stock is tracked across counters and a main store, with transfers and a single view of what is where.

Does it alert on low stock?

Yes. Reorder levels trigger low-stock alerts, so fast-moving drugs do not run out. It is part of the full hospital system.
