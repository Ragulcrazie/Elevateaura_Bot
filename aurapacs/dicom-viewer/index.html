Common questions

DICOM viewer, answered.

Do I need to install anything to view DICOM images?

No. The AuraPACS DICOM viewer runs in a standard web browser, so any authorised computer or laptop can open studies without installing heavy viewer software.

What viewer tools are included?

Windowing (brightness and contrast), pan, zoom, measurement, scrolling through series, and comparing a study with prior studies side by side.

Can radiologists read from home?

Yes. Because it is browser based with role-based access and remote viewing, an authorised radiologist can read from anywhere with a login. See cloud PACS.

Does it open CT, MRI and X-ray?

Yes. It reads DICOM studies from common modalities including CT, MRI, X-ray, ultrasound and CR/DR, fed by the modality worklist.

Is the viewer part of the full PACS?

Yes. The viewer is part of AuraPACS, which also stores images, runs a worklist and shares reports on WhatsApp.
