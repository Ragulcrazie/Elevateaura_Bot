Common questions

Diagnostic centre PACS, answered.

Do we need an IT team to run it?

No. AuraPACS is set up for you and runs on a lightweight on-premise node with cloud backup. It is designed for centres without a dedicated IT department.

Can referring doctors get reports easily?

Yes. Reports and images are shared as a secure WhatsApp link, so referrers open them without a login, which helps you keep their business.

Does it include billing?

Yes. GST-ready billing is tied to the study and patient, so the front desk and the imaging run on one system.

Will it work with our existing scanners?

Yes. It connects to common CT, MRI, X-ray and ultrasound units over DICOM, with a modality worklist.

How much does it cost?

Each setup is scoped to your centre's size and modalities. Tell us what you run and we will quote it clearly, with no per-seat surprises.
