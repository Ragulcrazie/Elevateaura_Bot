Common questions

Course management software, answered.

Can I build courses without technical help?

Yes. Instructors add modules, upload videos and notes, and set assessments from the dashboard, no coding required.

Can I drip-release content?

Yes. Lessons can unlock on a schedule or as learners progress, so a course paces itself instead of dumping everything at once.

Can I sell courses and bundles?

Yes. Price individual courses or bundles, run coupons, and collect GST-ready payments, with access granted automatically on purchase.

Is content protected?

Yes. Access is controlled per learner and batch, so paid content is not freely shareable. It fits inside the full LMS.

Does it include assessments?

Yes. Quizzes, tests and certificates can be attached to a course.
