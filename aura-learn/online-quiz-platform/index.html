Common questions

Online quiz platform, answered.

How is a quiz different from an exam here?

Quizzes are short, frequent and gamified, built for daily practice and engagement with instant feedback. Exams are the formal, timed, ranked assessments. Both live in the same platform.

Can we run a daily quiz?

Yes. A daily quiz can be scheduled automatically, with streaks and leaderboards that give learners a reason to return every day.

Does it give instant feedback?

Yes. Each answer is marked immediately with the correct option and a short explanation.

Are there streaks and leaderboards?

Yes. Streaks, points and leaderboards make practice a habit and add friendly competition.

Can quizzes push to WhatsApp or Telegram?

Yes. Reminders and daily questions can be nudged over WhatsApp and Telegram, as we do for our own exam-prep product.
